# Android Development Practice - Month 1

This branch contains my Android development progress for **Month 1** of my learning journey.

The primary focus during this month was understanding Android application architecture, building modern user interfaces with XML, implementing navigation between screens, and consuming REST APIs using Retrofit.

---

## 🎯 Learning Objectives

- Understand Android project structure
- Learn Fragment-based navigation
- Build responsive XML layouts
- Consume REST APIs
- Display API data using RecyclerView
- Follow MVVM architecture
